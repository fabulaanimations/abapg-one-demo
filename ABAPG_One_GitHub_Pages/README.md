# ABAPG One — Demo PWA

Demo funzionale dell'app istituzionale ABAPG One.

## GitHub Pages
Pubblicare il repository da **Settings → Pages → Deploy from a branch → main / root**.

La demo include:
- layout responsive;
- PWA installabile su iPhone/Android;
- timbratura geolocalizzata demo;
- QR temporaneo docente;
- firma presenza studente tramite QR;
- profili Docente, ATA, Studente, Segreteria e Amministratore;
- integrazione ISIDATA simulata.

> Nessun dato reale viene trasmesso.
