ABAPG One — Demo branded aggiornato

Novità:
- tasti principali in magenta;
- studente: firma presenza lezione tramite QR code;
- docente: generazione QR temporanei per il registro presenze studenti;
- layout responsive, quindi utilizzabile anche su smartphone.

Come aprirla su iPhone:
1. estrai i file su computer o hosting;
2. soluzione migliore: pubblica la cartella su un piccolo hosting / GitHub Pages / Netlify;
3. apri il link in Safari su iPhone;
4. da Safari usa Condividi > Aggiungi a Home per averla come web app.

Nota: se apri un file locale .html direttamente su iPhone è scomodo. Per l’uso su iPhone conviene metterla online oppure trasformarla in app con wrapper iOS.
