# ABAPG One — Demo PWA

Versione demo di ABAPG One pronta per GitHub Pages.

## Pubblicazione
In GitHub:
1. caricare **il contenuto di questa cartella nella root del repository**;
2. Settings → Pages;
3. Source: Deploy from a branch;
4. Branch: main;
5. Folder: /(root);
6. Save.

## iPhone
Aprire il link GitHub Pages con Safari → Condividi → Aggiungi a Home.
